# CareRescue 

## 展示帳號

- 帳號：`supervisor.demo`
- 密碼：`demo2026`

登入後固定使用居督模式。這是展示用驗證機制，不適合作為正式環境的身分驗證。

## 檔案說明

| 檔案 | 功能 |
| --- | --- |
| `login.html` | CareRescue 登入頁面，包含品牌識別、展示帳號與密碼欄位。 |
| `login.css` | 登入頁的主要排版、色彩、響應式配置與表單樣式。 |
| `brand-login.css` | 登入頁大型 Logo、CareRescue 與「照常營業」品牌文字樣式。 |
| `login.js` | 驗證展示帳號、建立登入狀態、顯示或隱藏密碼，以及導向主系統。 |
| `index.html` | 居督端主系統，包含總覽、異動、請假、決策、通知、人員班表與分析頁面。 |
| `styles.css` | 主系統所有頁面的視覺樣式、桌面與行動版配置。 |
| `app.js` | 主系統的資料、畫面渲染與互動邏輯，包括事件、請假、派班、班表、通知與瀏覽器資料保存。 |
| `mobile-leave.html` | 照服員手機版請假頁面。 |
| `mobile-leave.css` | 手機請假頁的行動裝置版面與元件樣式。 |
| `mobile-leave.js` | 手機請假送出、表單檢查、申請紀錄與主平台資料同步。 |

## 各頁面用途

### 今日量能總覽

顯示待處理異動數量、今日班次、可支援人力、量能比例，以及受影響服務和近期異動原因。

### 異動事件

建立及追蹤臨時請假、延誤、停服、送醫和需求變更。可設定服務時間、區域、項目、風險與限制條件。

### 請假管理

接收照服員提出的請假申請。居督核准後，系統會依照該人員班表建立需要補位的異動事件。

### 救援決策台

先排除資格、時程或工時不符的人選，再依照護連續性、交通及負荷排序候選方案。居督保留最終決策權，也可以自行選派人員。

### 通知與追蹤

集中顯示派班結果、通知對象、處理狀態、決策時間與決策者，作為稽核紀錄。

### 人員與班表

維護照服員姓名、區域、技能、資格狀態及每日班表。新增班次時會檢查時間是否與既有班次重疊。

### 量能分析

以模擬數據呈現平均處理時間、服務維持率、方案採用率、區域缺口與驗證 Roadmap。

### 手機請假頁

提供照服員填寫請假日期、時段、類型、原因與緊急程度，送出後可由主平台的居督端審核。

## 本機執行

本專案不需要安裝套件或建置工具。建議使用本機 HTTP 伺服器開啟，避免瀏覽器限制 `file://` 頁面的功能。

```bash
python3 -m http.server 4173 --bind 127.0.0.1
```

開啟：

- 登入入口：<http://127.0.0.1:4173/login.html>
- 手機請假：<http://127.0.0.1:4173/mobile-leave.html>
