# CareRescue 居服異動與量能救援台

CareRescue 是「照常營業」團隊為 2026 中化智匯盃製作的互動式情境原型。

本系統聚焦居家照護班表完成後發生的臨時異動，例如照服員臨時請假、服務延誤、停服、個案送醫或需求變更。系統協助居督掌握受影響服務、篩選可行人選、比較補班方案，並保留最終人工決策權。

> 本專案使用合成資料及模擬情境，不含真實個案、家屬或照服員個資，也不會發送真實通知。

## 核心流程

1. 照服員透過手機頁面提出請假申請。
2. 居督在請假管理頁核准或退回申請。
3. 核准後，系統找出受影響班次並建立異動事件。
4. 救援決策台依資格、時程、工時及交通條件提供候選方案。
5. 居督可以採用推薦方案，也可以自行指定照服員。
6. 確認後同步更新班表、案件狀態、通知紀錄與稽核紀錄。

## 主要功能

- 登入與登出流程
- 今日量能總覽
- 異動事件建立與狀態追蹤
- 照服員請假申請及居督審核
- 補班候選人篩選與多方案比較
- 居督自行選派照服員
- 人員資料與資格狀態管理
- 每日班表、新增班次及時間衝突檢查
- 派班完成後自動更新班表
- 通知與決策稽核紀錄
- 量能與異動原因分析
- 獨立手機版請假入口
- 使用瀏覽器 `localStorage` 保存展示資料

## 各頁面用途

### 今日量能總覽

顯示待處理異動數量、今日班次、可支援人力、量能比例，以及受影響服務和近期異動原因。

### 異動事件

建立及追蹤臨時請假、延誤、停服、送醫和需求變更。可設定服務時間、區域、項目、風險與限制條件。

### 請假管理

接收照服員提出的請假申請。居督核准後，系統會依照該人員班表建立需要補位的異動事件。

### 救援決策台

先排除資格、時程或工時不符的人選，再依照護連續性、交通及負荷排序候選方案。居督保留最終決策權，也可以自行選派人員。

### 通知與追蹤

集中顯示派班結果、通知對象、處理狀態、決策時間與決策者，作為稽核紀錄。

### 人員與班表

維護照服員姓名、區域、技能、資格狀態及每日班表。新增班次時會檢查時間是否與既有班次重疊。

### 量能分析

以模擬數據呈現平均處理時間、服務維持率、方案採用率、區域缺口與驗證 Roadmap。

### 手機請假頁

提供照服員填寫請假日期、時段、類型、原因與緊急程度，送出後可由主平台的居督端審核。

## 本機執行

本專案不需要安裝套件或建置工具。建議使用本機 HTTP 伺服器開啟，避免瀏覽器限制 `file://` 頁面的功能。

```bash
python3 -m http.server 4173 --bind 127.0.0.1
```

開啟：

- 登入入口：<http://127.0.0.1:4173/login.html>
- 手機請假：<http://127.0.0.1:4173/mobile-leave.html>

## 原型限制

目前版本屬於競賽展示與流程驗證用前端原型。正式上線仍需加入：

- 後端 API 與正式資料庫
- 安全的帳號驗證與角色權限
- 真實排班系統及企業資料介接
- 地圖、路線與交通時間服務
- 簡訊、Email 或 App 推播服務
- 個資加密、存取紀錄與備份機制
